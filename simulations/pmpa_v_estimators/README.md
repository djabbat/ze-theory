# PMPA overdetermination test — измерение Ze-скорости v тремя способами

Модуль к статье **«Proper Time as a Resource of Existence: The Ze Principle of
Mutual Predictive Adaptation and the Two-Slit Pattern»** (§7.6).

## Задача

Операциональный протокол из §7.6: Ze-скорость `v = K²` (which-path knowledge)
должна извлекаться из **трёх независимых наблюдаемых каналов** одного
двухщелевого прогона:

| Оценка | Канал | Формула |
|--------|-------|---------|
| `v1` | детектор (маркер) | `v1 = 1 − o_est²`, где `o_est` — измеренная верность маркерных состояний пути (калибровочные readout-ы) |
| `v2` | экран (видимость) | `v2 = 1 − (V_meas/V0)²`, где `V_meas` — контраст полос из гистограммы экрана |
| `v3` | delayed-choice (эйзер) | `v3 = 1 − (2P₊ − 1)²`, где `P₊` — доля событий в стёртом базисе `|+⟩` (статистика совпадений) |

## Две физические модели

- **Модель A (когерентная / Энглерт-насыщающая, стандартная КМ):**
  `|Ψ⟩ = (|ψ_A⟩|D_A⟩ + |ψ_B⟩|D_B⟩)/√2`, `⟨D_A|D_B⟩ = o`.
  Видимость `V = V0·o`, т.е. `V = √(1−v)` — закон видимости §6.5 совпадает с КМ.
- **Модель B (наивная материализация, буквальное прочтение Постулата I):**
  событие либо «корпускулярное» (which-path, вероятность `v`, классическое
  приземление), либо «волновое» (вероятность `1−v`, когерентное приземление).

Протокол — **дискриминатор**, а не тавтология: под Моделью A три оценки обязаны
совпадать (`v1 ≈ v2 ≈ v3 = 1−o²`), под Моделью B — расходиться с параметром `v`.

## Запуск

```bash
pip install -r requirements.txt      # только numpy
python3 sim_pmpa.py --all            # обе сетки, полный отчёт
python3 sim_pmpa.py --all --jackknife --blocks 24   # + джекнайф-SE
python3 sim_pmpa.py --model A --o 0.5
python3 sim_pmpa.py --model B --v 0.3
python3 sim_pmpa.py --all --plot pmpa_visibility.png
```

## Результаты (блок-джекнайф: R=24 блока, N≈240 000 событий/точка, калибровка ≈48 000, seed 7)

**Модель A — PASS во всей сетке `o ∈ [0,1]`** (взаимный разброс v₁,v₂,v₃ ≤ 0.004, SE ≤ 0.004):

| o | v_true=1−o² | v1 | v2 | v3 | V | вердикт |
|---|-------------|-----|-----|-----|-----|---------|
| 0.10 | 0.990 | 0.991±0.000 | 0.991±0.001 | 0.990±0.000 | 0.097±0.003 | PASS |
| 0.50 | 0.750 | 0.751±0.003 | 0.751±0.003 | 0.750±0.002 | 0.499±0.003 | PASS |
| 0.90 | 0.190 | 0.190±0.003 | 0.191±0.004 | 0.188±0.002 | 0.899±0.002 | PASS |

**Модель B — FAIL для `v ∈ (0,1)`**: три оценки взаимно согласованы (разброс ≤ 0.005), но дают `≈ 2v − v² ≠ v`:

| v | v1 | v2 | v3 | вердикт |
|---|-----|-----|-----|---------|
| 0.25 | 0.436±0.002 | 0.438±0.005 | 0.441±0.002 | FAIL (v_true mismatch) |
| 0.50 | 0.749±0.002 | 0.754±0.003 | 0.750±0.002 | FAIL (v_true mismatch) |
| 0.75 | 0.938±0.001 | 0.938±0.002 | 0.937±0.001 | FAIL (v_true mismatch) |

Воспроизводимо на других сидах; джекнайф-SE подтверждает статистическую стабильность оценок.

## Выводы

1. **Протокол §7.6 не тавтологичен**: он различает физические модели.
2. **Когерентное (Энглерт-насыщающее) прочтение Постулата I самосогласовано**:
   детектор, экран и эйзер дают одну и ту же `v = 1−o²` — это стандартная КМ.
3. **Наивная материализация отвергается**: измеряемая когерентность (≈2v−v²)
   «обгоняет» постулируемую скорость материализации `v` — модель внутренне
   непоследовательна относительно собственного параметра.
4. **Закон видимости §6.5 подтверждён** как QM-совместимый: измеренная
   `V = o = √(1−v)` на всех точках Модели A (в когерентном режиме Ze не
   отклоняется от КМ — соответствует честной рамке статьи).

# P6: категорийное истощение и квант рождения (§7, протокол P6)

`sim_p6.py` — численный тест двух прочтений информационной матрицы категории
(§5.5, Постулат VI): **архетип** (τ_c(0) одинаков для всех экземпляров,
бюджеты квантованы по τ₀) против **запаса** (каждое рождение истощает
матрицу: `τ_g = τ₀(1−γg)`, за порогом τ_min роды мёртвые). Протокол
полностью в геометрической реальности — только статистика времён жизни по
поколениям, без измерения предгеометрии.

Модель экземпляра: рождён с бюджетом τ_g, тратит τ со скоростью R
(логнормальная, среднее 1 — постоянная цена ошибки и внутренних контактов),
распадается при исчерпании: `T_gi = τ_g / R_gi`. Среднее время жизни
поколения — измеряемый прокси τ_g.

Запуск:
```bash
python3 sim_p6.py --all --jackknife
python3 sim_p6.py --model stock --gamma 0.05 --jackknife
python3 sim_p6.py --all --jackknife --plot p6_birth.png
```

## Результаты (G=12 поколений, 300 экз./поколение, τ₀=1, τ_min=0.3, γ=0.08)

**Поколенный тест:**

| Модель | slope | se(slope) | вымирание | вердикт |
|--------|-------|-----------|-----------|---------|
| архетип | −0.004 | 0.003 | нет (все 12 поколений живы) | **ARCHETYPE (стационарно)** |
| запас | −0.096 | 0.002 | g=9 (τ_g=0.28 < τ_min=0.3) | **STOCK (истощается)** |

Запас даёт значимый отрицательный наклон (>50σ) и обвал рождаемости до нуля
на конечном поколении — категория «вымирает». Архетип — плоская линия,
все роды жизнеспособны.

**Квантование (K=8 категорий, примитивный счёт n_c = c):**

| Модель | CV(measured/c) | смысл |
|--------|----------------|-------|
| архетип (τ_c = c·τ₀) | **0.019** | регулярный шаг n·τ₀ (арифметическая прогрессия) |
| континуум (τ_c непрерывно) | **1.029** | регулярного шага нет |

Общий множитель ⟨1/R⟩≈1.17 смещает абсолютные бюджеты, поэтому квантование
видно не по позиции, а по постоянству `measured/c` — арифметической
прогрессии бюджетов. CV≈0.02 у архетипа против CV≈1.0 у континуума —
дискриминация полная.

## Выводы (P6)

1. **Архетип и запас различимы без измерения предгеометрии**: стационарность
   распределения времён жизни по поколениям + регулярный шаг бюджетов →
   архетип; монотонный спад + вымирание категории → запас.
2. **Рабочая гипотеза «архетип» согласуется** с текущими данными (плоская
   линия, квантование), но остаётся открытой пересмотру — как и заявлено
   в §5.5 и Limitations п.7.
3. **Квант τ₀ наблюдаем**: если реальные бюджеты категорий ложатся на
   арифметическую прогрессию — конструкторский (лего) набор подтверждается;
   континуум бюджетов — нет.

# P6 в реальной физике: изотопы как «категория с экземплярами»

`sim_isotopes.py` — изотопы как реально измеренная система, где структура P6
(квантование + порог жизнеспособности + стационарность) уже реализована
природой. Энергии связи — по полуэмпирической формуле Вайцзеккера.

| P6-структура | Изотопный аналог | Измеряемый факт |
|---|---|---|
| категория | элемент (Z) | карта нуклидов |
| экземпляр | изотоп (A = Z+N) | A ∈ ℤ |
| бюджет τ(M_C) | масса ядра M(A,Z) | M ≈ A·m_u |
| квант τ₀ | атомная единица массы m_u ≈ 931.5 МэВ/c² | решётка по A |
| τ_min, «мёртвое рождение» | связанность (B>0) + устойчивость к делению (Z²/A<50) | долина стабильности |
| архетип (неистощимость) | карта нуклидов стационарна | элемент не «теряет» изотопы |

Результаты: массы ложатся на решётку A·m_u (наклон 1.011–1.013 m_u/нуклон
против идеала 1.000); окно жизнеспособности конечно и ограничено для каждого
элемента (Z=6: N∈[4,11], Z=26: N∈[15,51], …); карта из 7292 связанных
нуклидов стационарна; B/A пик у A≈54 (Z=26, Fe) — 8.63 МэВ.

**Честный статус (важно):** это АНАЛОГИЯ, которая укореняет паттерн P6 в
известной физике, а не тест Ze-теории. Квантование масс на решётке A и
ограниченная долина стабильности — эмпирические факты; отождествление их с
«квантом собственного времени предгеометрической матрицы» — интерпретация,
не вывод. Граница B>0 завышает жизнеспособность тяжёлых ядер (в реальности
долина уже из-за α-распада и др. мод, которых нет в массовой формуле) —
критерий Z²/A<50 частично это корректирует.

Запуск: `python3 sim_isotopes.py --all --plot p6_isotopes.png`
