# PMPA overdetermination test — измерение Ze-скорости v тремя способами

Модуль к статье **«Proper Time as a Resource of Existence: The Ze Principle of
Mutual Predictive Adaptation and the Two-Slit Pattern»** (§7.6).

## Задача

Операциональный протокол из §7.6: Ze-скорость `v = K²` (which-path knowledge)
должна извлекаться из **трёх независимых наблюдаемых каналов** одного
двухщелевого прогона:

| Оценка | Канал | Формула |
|--------|-------|---------|
| `v1` | детектор (маркер) | `v1 = 1 − o_est²`, где `o_est` — измеренная верность маркерных состояний пути (калибровочные readout-ы) |
| `v2` | экран (видимость) | `v2 = 1 − (V_meas/V0)²`, где `V_meas` — контраст полос из гистограммы экрана |
| `v3` | delayed-choice (эйзер) | `v3 = 1 − (2P₊ − 1)²`, где `P₊` — доля событий в стёртом базисе `|+⟩` (статистика совпадений) |

## Две физические модели

- **Модель A (когерентная / Энглерт-насыщающая, стандартная КМ):**
  `|Ψ⟩ = (|ψ_A⟩|D_A⟩ + |ψ_B⟩|D_B⟩)/√2`, `⟨D_A|D_B⟩ = o`.
  Видимость `V = V0·o`, т.е. `V = √(1−v)` — закон видимости §6.5 совпадает с КМ.
- **Модель B (наивная материализация, буквальное прочтение Постулата I):**
  событие либо «корпускулярное» (which-path, вероятность `v`, классическое
  приземление), либо «волновое» (вероятность `1−v`, когерентное приземление).

Протокол — **дискриминатор**, а не тавтология: под Моделью A три оценки обязаны
совпадать (`v1 ≈ v2 ≈ v3 = 1−o²`), под Моделью B — расходиться с параметром `v`.

## Запуск

```bash
pip install -r requirements.txt      # только numpy
python3 sim_pmpa.py --all            # обе сетки, полный отчёт
python3 sim_pmpa.py --model A --o 0.5
python3 sim_pmpa.py --model B --v 0.3
python3 sim_pmpa.py --all --plot pmpa_visibility.png
```

## Результаты (N=200 000 событий/точка, калибровка 40 000, seed 7)

**Модель A — PASS во всей сетке `o ∈ [0,1]`** (разброс оценок ≤ 0.009):

| o | v_true=1−o² | v1 | v2 | v3 | V | вердикт |
|---|-------------|-----|-----|-----|-----|---------|
| 0.10 | 0.990 | 0.992 | 0.990 | 0.991 | 0.098 | PASS |
| 0.50 | 0.750 | 0.757 | 0.750 | 0.751 | 0.500 | PASS |
| 0.90 | 0.190 | 0.191 | 0.182 | 0.187 | 0.904 | PASS |

**Модель B — FAIL для `v ∈ (0,1)`**: три оценки взаимно согласованы, но дают
`≈ 2v − v² ≠ v` (при v=0.5 все три ≈ 0.75, при v=0.25 ≈ 0.44):

| v | v1 | v2 | v3 | вердикт |
|---|-----|-----|-----|---------|
| 0.25 | 0.441 | 0.440 | 0.437 | FAIL (v_true mismatch) |
| 0.50 | 0.754 | 0.750 | 0.751 | FAIL (v_true mismatch) |
| 0.75 | 0.937 | 0.936 | 0.939 | FAIL (v_true mismatch) |

Воспроизводимо на других сидах (проверено: seed 42, N=100 000).

## Выводы

1. **Протокол §7.6 не тавтологичен**: он различает физические модели.
2. **Когерентное (Энглерт-насыщающее) прочтение Постулата I самосогласовано**:
   детектор, экран и эйзер дают одну и ту же `v = 1−o²` — это стандартная КМ.
3. **Наивная материализация отвергается**: измеряемая когерентность (≈2v−v²)
   «обгоняет» постулируемую скорость материализации `v` — модель внутренне
   непоследовательна относительно собственного параметра.
4. **Закон видимости §6.5 подтверждён** как QM-совместимый: измеренная
   `V = o = √(1−v)` на всех точках Модели A (в когерентном режиме Ze не
   отклоняется от КМ — соответствует честной рамке статьи).
